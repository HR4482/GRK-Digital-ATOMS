# Release candidate build
Use GitHub Actions > Build GRK Android APK for a debug installation artifact. For a signed release candidate, generate and back up your own keystore on a trusted computer. Never commit private signing keys or passwords. Add repository Actions secrets GRK_KEYSTORE_B64 (base64-encoded keystore bytes), GRK_KEYSTORE_PASSWORD, GRK_KEY_ALIAS and GRK_KEY_PASSWORD. Run Build signed GRK release APK manually. The workflow builds, tests, lints, aligns, signs, verifies and uploads the APK and checksum. A successful signed build is not evidence of acoustic quality. Complete real-device acceptance before release. Virtual DSP works on supported local PCM WAV; external playback session effects are experimental, not system-wide. This is not licensed Dolby Atmos.
